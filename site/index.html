Half of new homes took between 44 and 174 days (estimated). 48% took over 90 days; 24% over 180 days.

How we estimate this

The County's number counts only permits that were not returned for corrections (County metrics report), so it leaves out the slow ones. The County does not publish application dates per permit, so we estimate them: permit numbers (e.g. PW.B2025-002500) are assigned in order through each year, so we place each application date proportionally within its year (number ÷ year's highest number × days in year). Wait = issue date − estimated application date, for 941 new-dwelling permits issued in the last 12 months. This assumes applications arrive at an even pace; it is an estimate, not a County figure.
